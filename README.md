# Pulse Music Player

A simple, responsive music player built with TypeScript, HTML and CSS.

## Features

- Add multiple audio files from your device
- Play, pause, previous and next controls
- Seek bar and volume control
- Shuffle and repeat modes
- Removable playlist
- Keyboard shortcut: press Space to play or pause
- Responsive mobile layout

Your songs are loaded locally in the browser and are not uploaded anywhere.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Build

```bash
npm run build
```
